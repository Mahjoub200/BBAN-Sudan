# مولّد BBAN السوداني

تطبيق ويب ثابت (HTML/CSS/JavaScript) لإنشاء رقم BBAN مرشّح من رقم الحساب بعد اختيار البنك. الواجهة تدعم العربية والإنجليزية، والوضع الفاتح والداكن، وتعمل على الهاتف والحاسوب.

> **تنبيه مهم:** نجاح تركيب رقم من 14 خانة لا يثبت أن الحساب موجود أو نشط أو مملوك للشخص المقصود. بيانات البادئات واللواحق الموجودة في `banks.json` نُقلت من القائمة المضمنة في النسخة الأصلية للمشروع، ولم يتم اعتمادها هنا كمواصفات مصرفية رسمية. راجع كل صيغة مع البنك أو الجهة المصرفية المختصة قبل استخدامها في أي تحويل مالي. لا تستخدم الأداة للتحقق من ملكية الحساب.

## محتويات المشروع

- `index.html` — التطبيق الكامل.
- `banks.json` — قائمة البنوك التي يمكن تحديثها دون تعديل HTML.
- `assets/banks/` — مجلد اختياري لوضع شعارات البنوك.
- `.nojekyll` — إعداد بسيط للنشر على GitHub Pages.
- `.github/workflows/pages.yml` — سير عمل نشر GitHub Pages.

## التشغيل محلياً

**الطريقة الأسهل:** افتح `index.html` في متصفح حديث. قد لا يعمل التحديث البعيد من `banks.json` عند فتح الملف مباشرة بصيغة `file://` بسبب قيود المتصفح؛ استخدم خادماً محلياً بدلاً من ذلك:

### Python

```bash
python -m http.server 8000
```

ثم افتح:

```text
http://localhost:8000
```

### Node.js

```bash
npx http-server . -p 8000
```

## رفعه إلى GitHub

1. أنشئ مستودعاً جديداً على GitHub.
2. ارفع **محتويات هذا المجلد** إلى جذر المستودع، بحيث يكون `index.html` في الجذر بجانب `banks.json`.
3. افتح **Settings → Pages**.
4. اختر **GitHub Actions** كمصدر النشر.
5. ادفع الملفات إلى الفرع `main`؛ سير العمل الموجود في `.github/workflows/pages.yml` سينشر الموقع تلقائياً.

بعد اكتمال النشر، افتح رابط GitHub Pages الذي يظهر في صفحة Pages.

## تحديث قائمة البنوك

عدّل `banks.json` ثم ارفع التعديل إلى GitHub. التطبيق يطلب الملف عند بدء التشغيل ويحفظ آخر نسخة صالحة محلياً كنسخة احتياطية. يجب إبقاء أسماء الحقول كما هي:

```json
{
  "version": "2026-11-10",
  "banks": [
    {
      "id": "bank-id",
      "n": "اسم البنك بالعربية",
      "e": "Bank name in English",
      "p": "123",
      "s": "0001",
      "st": "unk"
    }
  ]
}
```

- `id`: معرّف لاتيني فريد.
- `n` و`e`: الاسم بالعربية والإنجليزية.
- `p`: بادئة رقمية.
- `s`: لاحقة رقمية، ويمكن أن تكون فارغة.
- `st`: إحدى القيم `ok` أو `unk` أو `bad` كما يتوقعها التطبيق الحالي. هذه العلامة لا تعني اعتماداً رسمياً.

**مهم:** لا تضف بادئات أو لواحق تخمينية. اختبر الصيغة مع البنك أولاً. يجب أن يكون مجموع طول `p` و`s` أقل من 14 حتى تبقى خانات لرقم الحساب.

## شعارات البنوك

ضع صورة باسم معرّف البنك داخل `assets/banks/`، مثلاً:

```text
assets/banks/khartoum.png
```

راجع قسم `LOGOS` داخل `index.html` لإضافة مسار الشعار وفق آلية المشروع الحالية. لا توجد شعارات مرفقة لأن النسخة المستلمة لا تحتوي على ملفات صور بنوك.

## الخصوصية والحدود

- لا يوجد خادم خلفي أو قاعدة بيانات في هذه النسخة.
- الحسابات والسجل والإعدادات تُدار في المتصفح محلياً وفق وظائف التطبيق.
- لا تُدخل بيانات مصرفية حقيقية إلا بعد مراجعة الكود وسياسة الخصوصية واحتياجات الحماية.
- تحميل `banks.json` يحدّث قواعد تركيب الرقم فقط؛ لا يتحقق من وجود الحساب أو صحته لدى البنك.
